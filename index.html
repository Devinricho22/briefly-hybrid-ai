How the hybrid engine works

  1. On-device first. In Auto mode, Firebase AI Logic runs Gemini Nano locally in Chrome — the text never leaves the device, it works offline and answers in milliseconds.
  2. Cloud fallback. If the on-device model is unavailable or the request is too large, the same call transparently falls back to cloud Gemini through Firebase AI Logic.
  3. You stay in control. Force either engine with the inference mode switch and watch the badge: every result is labelled with the engine that actually produced it.
